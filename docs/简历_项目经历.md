# 项目经历：Kronos 金融基础模型 A股复现与客观评估

- **角色**：独立复现 + 评估（项目发起 / 数据 / 建模 / 报告，端到端负责）
- **时间**：2026.11
- **技术栈**：Python · PyTorch(CUDA) · HuggingFace · akshare · plotly · Streamlit · bootstrap 统计检验

## 项目简介
复现 AAAI 2026 开源金融基础模型 **Kronos**（K-line Foundation Model），在 A 股真实
日线数据上做预测，并设计严谨评估检验其预测力。代码、数据管道、评估与可演示网页
全部进 GitHub 并上线。

## 做了什么
1. **从零搭推理环境**：独立 venv（Python 3.13，避开系统 3.14 的兼容坑）、CUDA 版
   PyTorch、HuggingFace 镜像拉取 Kronos-base 权重，在本地 RTX 4060 跑通端到端预测。
2. **数据管道**：复用自研行情层（东财→新浪三级回退 + 真实 A 股交易日历，剔除国庆/春节），
   把 A 股/ETF 日线转换为 Kronos 输入格式，生成“历史 K 线 + 未来分位扇形”交互预测图。
3. **严谨评估**：滚动窗口（4 标的 × 12 时点）对比 Kronos 与 4 个基线（动量 / 均值回归 /
   常数 / 随机），指标含方向准确率、IC、RankIC，并用 bootstrap(2000) 给出 IC 的 95% 置信区间。

## 核心结论（项目最大亮点）
在 A 股真实样本上，Kronos **无统计显著的预测力**（所有方法 IC 的 95% 置信区间均含 0）；
进一步定位到其预测行为**等价于“向窗口均值回归”这一行代码即可实现的基线**
（IC +0.130 vs +0.118），根因在模型内部的 z-score 标准化机制。

## 简历卖点（建议写法）
- 完整闭环：环境 → 数据 → 预测 → 严谨评估 → 可演示网页，全部进 GitHub 并上线。
- 方法论严谨：不盲信 SOTA，主动设计强基线、用 bootstrap 量化不确定性、如实报告“负结论”。
- 金融工程素养：与双均线策略、交易处置效应两条项目线共同体现“先证伪、再下结论”的研究习惯。
