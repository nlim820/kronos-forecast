## 踩坑清单（重要）

### 1. pip 全部走不通：403 + 空索引
- 现象：默认 PyPI 装 18 分钟零进展；清华源报 `from versions: none`；`-vvv` 显示 `GET /simple/tqdm/ 403`
- 根因：环境里存在 `HTTP_PROXY/HTTPS_PROXY=http://127.0.0.1:57092`（本地代理），pip 走代理被拒；同时镜像对 pip 的 UA 返回 403
- 解决：**两件事一起做**
  1. 清代理：`env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy pip install ...`
  2. 换源：阿里云 `-i https://mirrors.aliyun.com/pypi/simple`（清华源在 pip 下 403，urllib 直连却是 200）

### 2. 大文件下载必须断点续传
- torch cu126 Windows wheel = 2464 MB，pip 不支持续传，中断即重下
- 解决：先 `curl -L -C - -o <文件名>.whl <url>` 下到本地，再 `pip install <本地whl>`
- **文件名不能改**：pip 校验 wheel 文件名中的 python/平台标签，改名会报 `Invalid wheel filename`

### 3. HuggingFace 权重走镜像
- `HF_ENDPOINT=https://hf-mirror.com`，`HF_HOME` 指到项目内 `.cache/hf`
- Windows 无符号链接权限会告警，可设 `HF_HUB_DISABLE_SYMLINKS_WARNING=1`

### 4. DatetimeIndex vs Series
- `KronosPredictor.predict()` 的 `x_timestamp/y_timestamp` 必须是 `pd.Series`，传 `DatetimeIndex` 会报
  `'DatetimeIndex' object has no attribute 'dt'`

## 仓库结构要点

- `model/kronos.py` — 模型主体，`KronosPredictor.predict(df, x_timestamp, y_timestamp, pred_len, T, top_k, top_p, sample_count)`
- 内部对输入窗口做 **z-score 标准化**，输出后反标准化 → 模型对绝对价位不敏感，本质学"形态延续"
- `sample_count>1` 时返回多采样均值（非分布），要不确定性区间需直接调 `generate()`
- `predict_batch()` 支持多标的同长度并行
- `examples/prediction_cn_markets_day.py` — 官方 A 股日线示例（含 ±10% 涨跌停裁剪逻辑）
